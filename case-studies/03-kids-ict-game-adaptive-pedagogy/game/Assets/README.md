# Assets

The original artwork, recorded narration and videos belong to Rainbow Roots Academy and are not
published. Generate stand-ins with `python3 tools/make_placeholders.py` (see the setup guide in
`../README.md`), or place your own files at the same paths listed in `tools/asset-manifest.json`.

`Coiny-Regular.ttf` is the Coiny typeface by Astigmatic, licensed under the SIL Open Font
License 1.1 (https://openfontlicense.org), used for the game's display text.
